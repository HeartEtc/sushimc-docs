## 服务器玩法

寿司峰是一个群组服务器，运行着多个不同风格的整合包。这个列表随时会更新。

| 玩法 | 简介 |
|------|------|
| [**苍穹**](zenith.md) | 以养老、探索、建筑为主题的整合包，2026年7月公测上线，已发布正式版。[**了解更多**](zenith.md) |
| [**秘境**](eden.md) | 以农业，魔法，轻工为主题的混合玩法整合包，2025年上线，目前正在测试中。[**了解更多**](eden.md) |
| **新老登（WIP）** | 创造模式建筑服务器，目前不对外开放，并且正在复活中 |
