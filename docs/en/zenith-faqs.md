# Frequently Asked Questions

> Find answers to common questions other players run into while playing Sushi: Zenith. They may help you solve similar issues.

## High Memory Usage

Sushi: Zenith uses [BandwidthOptimizer](https://www.mcmod.cn/class/27110.html) to optimize network traffic, and the mod generates some cache files. If you notice the client's memory usage has **risen noticeably compared to when you first installed it**, consider deleting the `bandwidthoptimizer-native` folder under your instance folder.

## Crashing on Join

If you crash immediately upon joining the server, or when switching to another server, try clearing Voxy mod cache: delete the `.voxy` folder under your instance folder.

This folder may be hidden — show hidden folders in your explorer's settings to operate it.

## Mod Requests / Found a New Bug

If you'd like more mods added to the game, feel free to **suggest them to the admins in the player group** at any time. If your suggestion is accepted, the mods will be added in one of the upcoming updates.

Found a new bug? You can also report it in the player group. We'll look into it and release a patch as soon as possible.
