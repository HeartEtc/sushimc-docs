# Eden

![Eden logo](/images/en/logo-eden.png)

Sushi: Eden's first version was released on August 7, 2025. It is a modpack focused on **agriculture, magic, and light industry**. The server is currently in open beta.

---

## Theme Mods

- Create
- Iron's Spellbooks
- Immersive Engineering
- Farmers Delight
- Touhou Little Maid
- Timeless & Classics Guns
- Ars Nouveau
